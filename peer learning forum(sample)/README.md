# Peer Learning Forum

A small Python project that demonstrates a simple peer learning forum prototype.

## Overview

This repository contains a lightweight script that works with a JSON dataset of forum posts. It can be used as a starting point for exploring features like listing threads, searching posts, and basic analytics on community activity.

## Files

- `Peer Learning Forum.py` - Main Python script for interacting with the forum dataset.
- `forum_data.json` - Sample JSON dataset containing forum posts, users, and threads.
- `README` - (empty) original file left in place. Use `README.md` for the improved documentation.

## Requirements

- Python 3.8 or later

Optional: create and activate a virtual environment to keep dependencies isolated.

## Quick start

1. Open a terminal (PowerShell on Windows).
2. (Optional) Create a virtual environment and activate it:

   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

3. Run the main script:

   python "Peer Learning Forum.py"

The script will read `forum_data.json` from the repo root. If the script expects additional arguments, consult the top comments of `Peer Learning Forum.py` or open the file to see usage instructions.

## Data

`forum_data.json` contains example posts and metadata. Use it to experiment and extend the project — for example, add new posts, threads, or implement export features.
